# Съёмка кадров с ВМ для отчётов

Кадр — часть документа: он должен (1) показывать ровно то, что обещано в
подписи, (2) не содержать следов автоматизации, (3) не противоречить числам и
адресам в уже сданных разделах.

## Инструменты (scripts/, всё параметризовано окружением)

```bash
export CYVM="CyOps-L7" CYPORT=2227      # имя ВМ и хостовый порт SSH
./clone.sh CyOps-L7 2227 4096 4         # связанный клон со снимка baseline
./up.sh                                 # старт headless + вход + ждать SSH
./cy.sh 'hostname'                      # команда в госте по SSH
./cyx.sh 'wmctrl -l'                    # то же с DISPLAY=:0 (GUI/xdotool)
./shot.sh /tmp/a.png "имя-окна"         # кадр, обрезанный ровно по окну
./crop.sh /tmp/a.png                    # срезать пустой низ терминального кадра
```

## Как снимать правильно

1. **Снимок делает хост**: `VBoxManage controlvm "$CYVM" screenshotpng out.png`.
   Хватает всего экрана, дальше кроп. `xwd -id <окно>` с гостя даёт **пустой
   (двухцветный) кадр** — он читает пиксели рамки WM, а не терминала-ребёнка.
2. **Координаты окна — из `xwininfo`** («Absolute upper-left X/Y» — левый верх
   угол клиентской области) + `_NET_FRAME_EXTENTS` для полей рамки.
   `xdotool getwindowgeometry` возвращает значения, смещённые на толщину рамки:
   обрезка уезжает вниз-вправо и срезает половину строк.
3. **Фиксированная геометрия окна перед серией съёмок** — тогда кроп-прямоугольник
   детерминирован для всех кадров серии:
   `wmctrl -r :ACTIVE: -e 0,18,60,590,383` (или `xdotool windowsize/move`).
4. **Самое большое окно по имени**: `winpick.sh` выбирает максимум по площади —
   `xdotool search --name` находит и окна-заглушки 10×10 от неудачных запусков GUI.
5. **Пустой низ кадра** режет `crop.sh` (ищет последнюю непустую строку по
   средней яркости): окно на 30 строк с выводом в 8 строк съедает полстраницы отчёта.

## Чистота кадра

- Никаких команд автоматизации в кадре: ни `xdotool`, ни `xclip`, ни скриптов,
  ни `sudo env DISPLAY=… python2 topo.py` в видимой части. В кадре — только то,
  что ввёл бы человек.
- GUI-приложения запускать из гостя с явными `DISPLAY`/`XAUTHORITY`: `sudo` их
  срезает, и хост-оболочки из CLI минисети не открываются.
- Перед каждым вводом — `xdotool windowactivate --sync` + `windowraise`: фокус
  уходит от всплывающего окна, и `xdotool type` теряет половину нажатий.
- Прогресс-строки и сетевая активность в статус-баре — переходящие: нажать
  Escape (остановить загрузку) и только потом снимать.
- Диалоги «сохранить сессию/обновить браузер» допустимы как артефакт браузера,
  но лишние вкладки (`about:sessionrestore`) лучше закрыть: `xdotool key ctrl+w`
  (не `windowclose` — у однооконного Firefox это убивает весь процесс).

## Кадры должны согласовываться с уже вшитыми в документ

- MAC/IP/порты в новом кадре не должны противоречить старым кадрам и тексту.
  Если окружение генерирует адреса заново (минисеть, DHCP-клиент) — **закрепить
  значения до съёмки** (`ip link set … address …`), иначе новый кадр противоречит
  сентябрьскому.
- Кадры конфигурации самой ВМ (ifconfig/ip address) на клонах **не переснимать**:
  MAC клона расходится с уже вшитыми кадрами. Если существующий кадр покрывает
  вопрос целиком — закрыть вопрос без ВМ, зафиксировав это в TODO.
- Формат кадра подбирать под окружение документа: белые терминалы (xterm) и
  тёмные (xfce4-terminal) обрезаются по-разному — см. references/gotchas.md.

## Серия съёмок: порядок действий

1. клон + `up.sh` (по одному ВМ за раз: одна GPU/одна машина — параллельность
   съёмок вредит, а не ускоряет);
2. закрепить адреса/параметры окружения;
3. задать геометрию окон;
4. снять серию `shot.sh`, сразу `identify` + проверка яркости
   (`-format "%[standard-deviation]"` ≈ 0 ⇒ пустой/чёрный кадр; 800×600 ⇒ залипший стафф);
5. семантическая приёмка монтажами — скилл `report-teacher-review`
   (`caption_montage.py`): то ли окно, нет ли протечки автоматизации;
6. выключить ВМ (`poweroff`, не `suspend`), обновить TODO.

## Известные грабли (детали — references/gotchas.md)

SSH в госте деградирует после запуска минисети (до 2 мин на вызов, может
зависнуть) — батчить команды и снимать с хоста; `pkill -f firefox` убивает
собственную SSH-сессию (паттерн матчится на свою командную строку) — `pkill -x`;
`ifconfig ethA ethB` даёт «Host name lookup failure» (второй аргумент — алиас);
CLI минисети чувствителен к регистру имён узлов; Ctrl+E в Wireshark 2.6 не
возобновляет захват, запущенный с `-k -i`; активный режим FTP через NAT не
работает — `passive`; часть сайтов (Cloudflare) отдают 403/пустую страницу из
гостя — тогда сниматься через web.archive.org и честно помечать источник.
